# Training material

Drop transcript collections, swipe files and course notes here (for example
`meta_ad_creative_training_transcripts.md`). Full transcripts are other people's words, so they stay
on this machine: everything in this folder except this README is ignored by git.

What gets committed instead is the distilled rules, each credited to its source, in:
- `brand/DESIGN.md` (what we adopted from each reference and why)
- `.claude/skills/ad-batch/reference/*.md` (style guide, editing, hooks, launch rules)
- `playbook/facts.yaml` (dated, sourced facts about Meta delivery and creative)

To process a new file: drop it here and tell Claude in a session "process the new training file".

# Design references

Drop screenshots, short screen recordings, or saved ads whose look you want here (5 to 10 is plenty).
Add one line per file in NOTES.md saying what you like about it: the captions, the way text enters,
the card shapes, the pacing, the sound, the colors.

At the start of the next session the editor views every file, writes `brand/DESIGN.md` (what the
references share and what to adopt), and applies it by editing `tools/plates/theme.css` and the
style guide, never by one-off styling inside an ad. Media here is not committed to git.
